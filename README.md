## Descripción del Proyecto

Este proyecto consiste en el diseño e implementación de una plataforma gestión de farmacias, con el objetivo de aplicar las practicas DevOps aprendidas durante el curso.

El sistema tiene como objetivo gestionar farmacias y sus medicamentos, abarcando desde la creacion de medicamentos hasta la compra de los mismos.
